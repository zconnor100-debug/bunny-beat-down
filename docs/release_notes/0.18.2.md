## Bunny Beat Down v0.18.2: smoother on a laptop's graphics chip

**The Hamster Cage and Toy Box Bash draw faster on a weaker GPU.** Measured on a processor's built-in graphics (a Ryzen's Radeon), at Low: a Hamster Cage frame takes 29% less time to draw and a Toy Box frame 26% less. It wasn't how many things there are to draw that cost the time, it was the floor: the cage floor's shader looked up the sand, the aquarium gravel and the snow for every pixel, even on plain bedding. Now each layer is only looked up where it shows, and the Toy Box floor's rug, boards and quilt the same way. The picture is the same, pixel for pixel.

**Low is lighter.** No bloom, and two shadow cascades instead of four (the near one longer). The tank's glass no longer works out shadows (on clear glass they never showed), and the water no longer blurs a copy of the screen it never used.

**A laptop starts at Low.** The first time the game runs on a graphics chip built into the processor, it starts at Low, where it plays smoothly, instead of High. A graphics card still starts at High, and nothing changes for anyone who's already picked a setting.
