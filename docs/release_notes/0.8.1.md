## Bunny Beat Down v0.8.1: better voices, one-file Windows build

**Clearer, more natural voices.** Every rogue has been recast using only Kokoro's best-rated voices, so nobody sounds robotic any more; each still has a voice of its own (pitched for its animal, paced for its personality), and the nobles are still frightfully British.

**Windows: the whole game is one file.** `BunnyBeatDown.exe` now carries the game inside it, so it runs wherever you put it (no more "Couldn't load project data ... Is the .pck file missing?" if only the .exe was copied out of the zip). Every Windows build is now started and checked on Windows before it's released.
